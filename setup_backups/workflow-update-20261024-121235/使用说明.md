# 煤堆仓库手动飞行示例

入口：双击桌面 `Coal Warehouse - Manual Flight`，或本目录 `launch_warehouse.bat`。
首次加载可能需要约 1–3 分钟；请等场景和右侧控制面板出现。只启动一个实例。

## 操作

切换英文输入法，点击仿真窗口，然后操作：

| 按键 | 功能 |
|---|---|
| T | 起飞到 2 米 |
| W / S | 按无人机朝向前进 / 后退 |
| A / D | 左右平移 |
| Q / E | 左右转向 |
| ↑ / ↓ | 上升 / 下降 |
| H | 立即设定当前位置为悬停目标 |
| L | 自动缓慢降落，着地后停桨 |
| R | 重置到起飞坪 |
| F / O | 跟随视角 / 仓库总览 |
| V | 隐藏或显示屋顶；碰撞仍保留 |

松开移动按键会减速并悬停。飞行速度上限 1.5 米/秒，高度上限 6.5 米。
撞击后若出现 FAULT，按 R 重置。右侧按钮也可控制起飞、悬停、降落和视角。
关闭 Isaac Sim 窗口即可退出。不要在飞行中修改无人机的 Stage 变换。

## 验收演示顺序

1. 按 O 展示开放仓库、8 个煤堆、钢结构和中央通道。
2. 按 F 返回跟随视角，按 T 起飞。
3. 按 W 沿通道前进；使用 A/D 和 Q/E 展示平移和转向。
4. 在煤堆间隙穿梭，松开按键展示悬停。
5. 返回空旷地面，按 L 降落。

## 文件

- `warehouse_app.py`：启动、控制面板、键盘、视角及验收测试。
- `manual_backend.py`：Pegasus 自定义辅助飞控，输出旋翼转速。
- `scene_builder.py`：仓库、煤堆、材质、碰撞的参数化建模代码。
- `coal_warehouse.usda`：可在 Isaac Sim 中打开编辑的场景。单独打开 USD 仅加载场景与物理模型；手动飞控需要使用启动脚本。
- `scene_metadata.json`：场景尺度、煤堆数据、实际无人机质量。
- `logs/acceptance_result.json`：程序化飞行和碰撞检查结果。
- `logs/runtime_console.log`：最近一次启动的运行日志。

## 已配置范围

Isaac Sim 5.1.0 + 官方 Pegasus Simulator v5.1.0 + Iris 无人机模型。
飞行使用 Pegasus 旋翼推力与 PhysX 刚体动力学，配有自定义 Python 位置保持控制器。
当前模式不需要 PX4、QGroundControl 或 ROS 2。老师如果额外要求 PX4 软件在环或真实遥控器，需要另行集成；这不包含在此版本。

针对 RTX 5060 Laptop 8GB / 16GB 内存采用实时渲染、DLSS 性能档、960×540 渲染分辨率、CPU 120Hz 物理和单无人机；煤堆共 3840 个三角形。复杂摄影测量资产、视觉模型与大量传感器尚未加入。

Pegasus 官方没有测试 Windows。当前 Windows 环境使用了两处可追踪兼容调整：
1. 资产菜单生成时跳过远程资产根目录检查，实际场景与 Iris 仍按本地文件加载。
2. 本示例设置 PEGASUS_DISABLE_ROS2=1，跳过不用的 ROS 后端自动导入。
原文件备份位于 `E:\isaacsim\setup_logs\pegasus_params.original.py` 与 `pegasus_backends.original.py`。
官方安装脚本添加 People 扩展依赖前的原始 Kit 配置也在 setup_logs 内备份。

仓库按 48×30 米搭建，煤堆为静态碰撞网格，不模拟煤粒散落。正常飞行通过推力实现，重置操作会把飞机恢复至起点。
