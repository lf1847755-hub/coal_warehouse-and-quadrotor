# 煤堆仓库手动飞行（Isaac Sim 5.1 + Pegasus）· 移交说明

## 1. 对方需要什么环境

| 项目 | 要求 | 本机实际 |
|---|---|---|
| 操作系统 | Windows 10/11 x64（Pegasus 官方只测 Ubuntu，本项目在 Windows 上验证过） | Windows |
| 显卡 | NVIDIA RTX，显存 ≥ 8 GB | RTX 5060 Laptop 8 GB |
| 驱动 | 支持 Blackwell 的新驱动（本机 592.82 验证通过） | 592.82 |
| 仿真器 | **Isaac Sim 5.1.0**（Windows 版，解压即用，约 10 GB） | 5.1.0-rc.19+release.26219，`E:\isaacsim` |
| 扩展框架 | **Pegasus Simulator v5.1.0**（必须是配 Isaac 5.1 的 5.1 分支） | 5.1.0，`E:\isaacsim\PegasusSimulator` |
| Python | Isaac Sim 自带 Kit Python 3.11.13，**不要另建 conda/venv** | 3.11.13 |
| 额外 pip 包 | `pymavlink`（Pegasus 运行时依赖，pip 自动装） | pymavlink 2.4.49 |
| 数值库 | numpy 1.26 / scipy 1.15 由 Isaac 自带（pip_prebundle），无需装 | 自带 |
| ROS 2 / DDS | **不需要** | 未安装 |
| PX4 / ArduPilot / QGC | **不需要** | 未安装 |

## 2. 一次性安装步骤

记 Isaac Sim 解压目录为 `%ISAACSIM%`（本机 `E:\isaacsim`）。

1. 解压 Isaac Sim 5.1.0 到 `%ISAACSIM%`。
2. 把 Pegasus Simulator v5.1.0 源码放到 `%ISAACSIM%\PegasusSimulator`。
3. 编辑 `%ISAACSIM%\apps\isaacsim.exp.base.kit`，在 `[dependencies]` 段第一行加：
   ```toml
   "isaacsim.replicator.agent.core" = {}
   ```
4. 把 pegasus 以 editable 方式装进 Kit Python（本机就是这么装的，已由
   `site-packages\__editable__.pegasus_simulator-5.1.0.pth` 与
   `direct_url.json` 的 `"editable": true` 证实）：
   ```bat
   "%ISAACSIM%\python.bat" -m pip install -e "%ISAACSIM%\PegasusSimulator\extensions\pegasus.simulator"
   ```
   首次安装需要联网（会拉 pymavlink）。
5. 打两处 Pegasus 本地补丁（见第 4 节），也可以直接运行仓库里的脚本：
   ```bat
   docs\apply-pegasus-patch.bat "%ISAACSIM%\PegasusSimulator\extensions\pegasus.simulator"
   ```
6. 从 GitHub 克隆项目（必须和 `PegasusSimulator` 同级，见第 5 节）：
   ```bat
   git clone https://github.com/lf1847755-hub/coal_warehouse-and-quadrotor.git "%ISAACSIM%\coal_warehouse"
   ```
7. 双击 `launch_warehouse.bat`（或建桌面快捷方式指向它，工作目录设为该文件夹）。

## 3. 文件来源

### 项目本体：GitHub，不用单独发

仓库 <https://github.com/lf1847755-hub/coal_warehouse-and-quadrotor>（public，无需授权），含全部 6 个 `.py`、`coal_warehouse.usda`、`scene_metadata.json`、`launch_warehouse.bat`、`README.md`。clone 下来即可，但要注意：

- 仓库里也提交了 `logs\`（约 4.6 MB）、`__pycache__\`、`setup_backups\`（约 1.1 MB），会被一起拉下来，**不影响运行**，可忽略或删掉。
- `launch_warehouse.bat` 里 `ISAACSIM_PATH=E:\isaacsim` 是硬编码的；对方路径不同就要改。
- 目录名无所谓（脚本用 `%~dp0`），但**必须与 `PegasusSimulator` 同级**。

### 安装文档与补丁：也在仓库 docs/ 里

| 文件 | 作用 | 能否省 |
|---|---|---|
| `docs\pegasus-5.1.0-local-changes.patch` | 两处 Pegasus 改动的统一 diff（-p1，相对 `extensions\pegasus.simulator`） | 不能 |
| `docs\apply-pegasus-patch.bat` | 一键打补丁，自动判断是否已应用（需要 Git for Windows） | 能，但会退化成手工改两处 |
| `docs\安装与交接说明.md` | 完整安装步骤、目录要求、排错（就是本文件） | 能，但对方会反复问 |

`apply-pegasus-patch.bat` 与 `.patch` 必须放在同一个目录（脚本用 `%~dp0` 找补丁），所以两者都放 `docs\`。

### 不属于项目、也不用发的

- Isaac Sim 本体（10 GB，让对方装同版本）
- Pegasus 源码（120 MB，让对方取官方 v5.1.0；仅 `extensions\` 就 51 MB）
- `setup_logs\*.original.py`（只是给你自己对照补丁用的，发不发都行）

## 4. 必须改的几处（Pegasus 两处已导出为补丁）

两处 Pegasus 源码改动已经导出为 `pegasus-5.1.0-local-changes.patch`，用同目录的
`apply-pegasus-patch.bat` 一次应用即可（打进 `extensions\pegasus.simulator`，等价于
`git apply -p1`，重复执行会提示已应用）。没有 Git 时按下面手工改。

### (a) `%ISAACSIM%\apps\isaacsim.exp.base.kit`
`[dependencies]` 首行加 `"isaacsim.replicator.agent.core" = {}`（Pegasus 扩展声明依赖它，base 体验默认没有）。

### (b) `...\pegasus\simulator\logic\backends\__init__.py`
把 ROS2 后端的 try/except 改成受环境变量控制：

```python
# Check if the ROS2 package is installed
try:
    import os
    if os.environ.get('PEGASUS_DISABLE_ROS2') == '1':
        raise ImportError('ROS2 is disabled for the local manual flight demo')
    from .ros2_backend import ROS2Backend
except:
    import carb
    carb.log_warn("ROS2 package not installed. ROS2Backend will not be available")
```

### (c) `...\pegasus\simulator\params.py`
跳过联网检查资产根目录（本机离线/本地场景需要）：

```python
NVIDIA_ASSETS_PATH = str(nucleus.get_assets_root_path(skip_check=True))
```

### (d) 路径不同时
`launch_warehouse.bat` 里的 `set ISAACSIM_PATH=E:\isaacsim`，以及桌面快捷方式的目标/工作目录，改成对方的实际路径。

## 5. 目录结构必须保持

```
%ISAACSIM%\
├─ apps\isaacsim.exp.base.kit
├─ PegasusSimulator\extensions\pegasus.simulator\...
└─ coal_warehouse\
   ├─ warehouse_app.py 等脚本
   └─ coal_warehouse.usda   ← 内含 @../PegasusSimulator/extensions/.../iris.usd@
```

`coal_warehouse.usda` 用**相对路径**引用 Pegasus 的 Iris 无人机资产，所以 `coal_warehouse` 与 `PegasusSimulator` 必须是同一个 `%ISAACSIM%` 下的兄弟目录；换盘符可以，换层级不行。

## 6. 验收自检

1. 启动后右侧出现控制面板，日志出现 `WAREHOUSE_READY`（首次 1–3 分钟，含 shader 编译）。
2. `logs\runtime_console.log` 无 ERROR；出现 `ROS2 package not installed. ROS2Backend will not be available` 是**正常现象**，说明 ROS 后端被主动禁用。
3. 按 `T` 能起飞悬停、`L` 能降落。
4. 可选自检（不开界面）：
   ```bat
   "%ISAACSIM%\python.bat" coal_warehouse\warehouse_app.py --self-test
   "%ISAACSIM%\python.bat" coal_warehouse\warehouse_app.py --workflow-test
   ```

## 7. 常见坑

- **版本必须锁 5.1.0**：项目用了 `isaacsim.storage.native`、5.1 的物理/关节 API，换 5.0 或 4.5 会直接报错。
- **必须用 `python.bat`**，不要用系统 Python 或 conda（会缺 `isaacsim`、`pxr`、numpy 路径）。
- 显存不足时，改 `warehouse_app.py` 里 `width/height` 与 `--/rtx/post/dlss/execMode`。
- 项目 Python 脚本里**没有**硬编码盘符，只有 bat 和快捷方式需要改。
- 若对方装了 ROS 2 并想启用，去掉 `PEGASUS_DISABLE_ROS2=1` 并启用 `isaacsim.ros2.bridge` 扩展即可，与本项目当前配置互不冲突。
- `apply-pegasus-patch.bat` 依赖 `git`（Git for Windows 即可）；没有 Git 时用第 4 节的代码片段手工替换，效果完全相同。
- 仓库当前是 public，对方直接 clone，不需要授权；若以后改成 private，记得加对方为 Read 协作者。
